# JavaScript · Ejercicios de aprendizaje

Ejercicios de JavaScript sobre fórmulas de figuras geométricas e interacción con HTML.

## Propósito

Repositorio de práctica del curso de JavaScript. `figuras.js` contiene los ejercicios y `index.html` su interfaz. Se conserva como historial de aprendizaje, separado de los productos y proyectos de portafolio.

## Uso

Abre la página desde un servidor estático. Consulta el material del curso correspondiente para el contexto de los ejercicios.
